| Término | Qué es |
|---|---|
| CD | Entrega o despliegue continuo: publicación automática si todo pasa |
| CI | Integración continua: comprobaciones automáticas de cada cambio |
| Clave SSH | Par de claves que identifica tu ordenador ante GitHub sin contraseña |
| Commit | Instantánea guardada de los cambios, con autor y mensaje |
| Contenedor | Una imagen de Docker en ejecución |
| Dockerfile | Receta para construir una imagen |
| Imagen | Paquete cerrado con sistema base, dependencias y código |
| MDM | Software con el que una empresa gestiona y supervisa sus equipos |
| Open Graph | Etiquetas HTML que definen la vista previa al compartir un enlace |
| Pull request (PR) | Propuesta de fusionar una rama en `main`, donde se revisa y se comprueba |
| Rama (branch) | Línea de trabajo paralela a `main` donde se prepara un cambio sin afectar a lo publicado |
| Registro | Almacén de imágenes de Docker (Docker Hub, ghcr.io) |
| Repositorio | Carpeta de proyecto con todo su historial en git |
| SDD | Spec-Driven Development: especificar antes de que el agente programe |
| Workflow | Fichero YAML que define una automatización de GitHub Actions |

Línea de prueba — con guion largo.
